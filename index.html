Guía de Ejecución en Postman (4 Consultas)

1

Importar la Colección en Postman

Abra Postman, presione el botón Import (esquina superior izquierda) y seleccione el archivo Parcial2_Nexus_API.postman_collection.json ubicado en la raíz de este proyecto.

2

Verificar Servidor Local

Asegúrese de tener el servidor corriendo ejecutando run.bat o abriendo PowerShell y ejecutando .\server.ps1 en el puerto 5000.

3

Las 4 Consultas Incluidas

1. GET /api/projects: Lista consolidada de proyectos con filtros.
2. GET /api/projects/PRJ-101: Detalle técnico y métricas de calidad.
3. POST /api/projects: Creación de proyecto (JSON Payload + Status 201).
4. GET /api/reports/analytics: Reporte global de cobertura y SLA.

4

Ejecución con Pruebas Automatizadas (Tests)

Todas las peticiones incluyen scripts de prueba (pm.test) en JavaScript para validar el código de respuesta HTTP y la integridad del esquema JSON de manera instantánea.

Sobre Qué Trata el Proyecto (Nexus Core Platform)

Nexus Core es una plataforma integral de ingeniería de software diseñada para la auditoría, gobernanza y telemetría de calidad de código en entornos de integración y despliegue continuo.

Normas & Calidad
Métricas de mantenibilidad y cobertura bajo estándar ISO/IEC 25010 y planes de prueba IEEE 829.
4 Consultas REST
Listado filtrado, telemetría por ID, registro con código 201 y analítica global de SLA.
Pruebas en Postman
Colección v2.1.0 automatizada con aserciones JavaScript (pm.test) listas para evaluar.
Diseño & UX
Estética Dark Glassmorphism, transiciones suavizadas y cero (0) emojis.
